# Sergey-Shark.github.io

Открытый сайт для проекта **«Управление качеством продукции»** ([vk-tmc-journal](https://github.com/Sergey-Shark/vk-tmc-journal), закрытый).
Адрес сайта: https://sergey-shark.github.io/

## Что где лежит

| Что | Где | Адрес в браузере |
|---|---|---|
| **QR-коды ярлыков** — страница «Информация о партии ТМЦ» | папка `qr/` | `https://sergey-shark.github.io/qr/#<ключ ярлыка>` |
| **Данные QR-кодов** — зашифрованные снимки партий | ветка `data`, папка `d/` | (читает страница QR-кодов) |
| **Презентация** «Управление качеством продукции» | папка `presentation/` (`show.html` — сама презентация, `index.html` — открывает её всегда в свежей версии) | https://sergey-shark.github.io/presentation/ |

В корне — только этот README и служебный пустой `.nojekyll` (GitHub отдаёт файлы сайта как есть).

## Важно

- **Папку `qr/` не переименовывать:** её адрес напечатан в QR-кодах ярлыков. Страницу `qr/index.html` программа
  обновляет сама (`db/qr_cloud.py` в основном проекте, с версии 10.4), остальное на сайте не трогает.
- **Презентация** — копия `index.html` из закрытого репозитория
  [vk-tmc-journal-presentation](https://github.com/Sergey-Shark/vk-tmc-journal-presentation) (там оригинал и исходники).
  После правок презентации копию обновлять здесь же.
- Новые материалы класть **в свою папку** (как `presentation/`), не в корень.
